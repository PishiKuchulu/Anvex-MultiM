# Persian lines are the product owner's planning directives with markdown markers removed; meaning unchanged.
Transform Anvex from a single-agent AI coding application into an advanced, extensible, multi-agent software development environment.
The system must support multiple AI agents working collaboratively on the same software project, using different AI models, providers, tools, roles, and execution strategies.
Select a different AI provider and model for each agent.
Configure individual temperature and other supported model parameters.
Assign the same task to multiple agents.
Run multiple agents simultaneously.
Define task dependencies and execution order.
Compare independent implementations.
Approve, reject, modify, or reassign tasks.
Pause, resume, or terminate individual agents.
Control which agents can read, modify, execute, or approve project changes.
Agents must not mark their own work as successfully verified merely because their implementation process completed.
The system must never silently overwrite another agent's changes.
An agent must never be able to bypass mandatory verification gates simply by requesting approval from the Project Manager.
Parallel execution must be based on task dependencies and actual file-level conflicts, not simply the number of available agents.
Isolated agent workspaces.
Merge and conflict resolution.
Rollback and recovery.
Per-agent token consumption tracking.
Configurable execution budgets.
Maximum concurrent agent limits.
Interrupted execution recovery.
Agent messages and generated content must be treated as untrusted input unless independently validated.
Secure credential handling.
Governance enforcement must not depend on the selected AI provider or model.
Avoid repeatedly sending the entire project source code to every model. Use relevant context retrieval and controlled context distribution.
Add new agent types without modifying the core orchestration engine.
Design the architecture so that the following capabilities can be added without redesigning the core engine:
Compatibility with the existing Anvex architecture.
No unnecessary external infrastructure dependencies.
PFP must remain the authoritative governance layer.
Git branches and Git Worktrees where supported.
A central Project Manager Agent manages a team of specialized subordinate agents.
Import and export agent configurations.
