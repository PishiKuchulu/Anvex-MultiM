# UX Principles

> Package: Anvex Agent Teams (multi-agent module) · PFP 5.7.0 · 2026-11-05

## Purpose

Give the team a short list of principles to settle design disputes.

## Scope

All screens of the module.

## Requirements

1. The user is in control: nothing destructive happens without an explicit action.
2. Show the cost and the consequence before the action.
3. Never hide a failure; show what failed, why and what to do.
4. Calm density: show important status first, details on demand.
5. Same meaning, same wording and same icon in English and Persian.

## Decisions

- Principle 1 outranks speed: an extra confirmation is acceptable.

## Rules

1. A design that violates a principle needs a recorded decision.
2. Test every screen at 200 percent font scale.

## Examples

Showing "3 conflicts, nothing applied" is preferred over a generic "Merge failed".
